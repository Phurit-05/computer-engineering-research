# รายงานการสืบค้นบทความวิจัยด้านวิศวกรรมคอมพิวเตอร์ (Computer Engineering)

## 1. ประเด็น: Cybersecurity
* **ชื่อบทความ:** การวิเคราะห์แนวโน้มการโจมตีทางไซเบอร์และแนวทางการป้องกันเชิงรุกจากข้อมูล ระบบป้องกันแอปพลิเคชันเว็บ
* **ผู้แต่ง:** อภิสิทธิ์ เจือตี๋
* **ปีที่พิมพ์:** 2025
* **ชื่อวารสาร:** วารสารวิชาการ "การประยุกต์ใช้เทคโนโลยีสารสนเทศ"
* **ลิงก์อ่านบทความ:** [อ่านเอกสาร PDF](document1.pdf)

## 2. ประเด็น: Artificial Intelligence
